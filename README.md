# stockpile-volume-computation-
A Python-based 3D Computer Vision project that computes the volume of a stockpile (such as sand, gravel, or soil) from a .ply point cloud file using Open3D, NumPy, and SciPy.  This project demonstrates practical applications of:  3D Point Cloud Processing Plane Segmentation using RANSAC Mesh Generation Delaunay Triangulation Volume
